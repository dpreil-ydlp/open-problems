# A182749: a(n) > 0 for all nonsquarefree n except for n = 4.

## Statement

> a(n) > 0 for all nonsquarefree n except for n = 4.

## Context

a(n) is the smallest n-digit multiple of n with exactly n divisors; a(n)=0 if no such number exists.

## Why it may be tractable

The statement uses only divisibility, divisor counts, and digit length. The construction might be handled by choosing a prime-power shape and controlling its size.

## Limits and cautions

The definition asks for a multiple with exactly n divisors and exactly n digits; finding one for every nonsquarefree n may require delicate size control.
