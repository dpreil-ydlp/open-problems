## Statement (verbatim)

```text
Is there  $A\subseteq \mathbb{N}$ such that\[\lim_{n\to \infty}\frac{1_A\ast 1_A(n)}{\log n}\]exists and is $\neq 0$?
```

## Site remarks, known results, and literature (verbatim)

```text
A suitably constructed random set has this property if we are allowed to ignore an exceptional set of density zero. The challenge is obtaining this with no exceptional set. Erd\H{o}s believed the answer should be no. In \cite{Er80} he explicitly asked whether there exists such a set where the limit is $1$ (and did not believe there existed such a sequence).

Erd\H{o}s and S\'{a}rk\"{o}zy proved that\[\frac{\lvert 1_A\ast 1_A(n)-\log n\rvert}{\sqrt{\log n}}\to 0\]is impossible. Erd\H{o}s suggests it may even be true that the $\liminf$ and $\limsup$ of $1_A\ast 1_A(n)/\log n$ are always separated by some absolute constant.

Horv\'{a}th \cite{Ho07} proved that\[\lvert 1_A\ast 1_A(n)-\log n\rvert \leq (1-\epsilon)\sqrt{\log n}\]cannot hold for all large $n$.
```

### Comment 1

> A recent preprint by Christian Táfula, "Representation functions with prescribed rates of growth" (arXiv:2405.01530, last revised May 2026), provides new insights right at the logarithmic boundary:
> 
> 1. Above the boundary: The paper proves that if $F(n)$ is a regularly varying function satisfying $\lim_{n \to \infty} F(n)/\log n = \infty$, then there exists a set $A \subseteq \mathbb{N}$ such that $1_A * 1_A(n) \sim F(n)$. This establishes that any rate of growth strictly faster than $\log n$ is attainable.
> 
> 2. The logarithmic sparsity wall: The paper presents a probabilistic heuristic indicating that if $A \subseteq \mathbb{N}$ satisfies
> 
> $$\limsup_{n\to\infty} \frac{1_A * 1_A(n)}{\log n} < 1,$$
> 
> then $1_A * 1_A(n) = 0$ for infinitely many $n$.
> 
> Since a limit $\lim_{n \to \infty} (1_A * 1_A(n))/\log n = c > 0$ requires the representation function to be positive for all sufficiently large $n$, this heuristic strongly implies that no such limit can exist for any constant $c < 1$.
